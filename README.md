# soundgo-edu (초6 체험형 음악) — v1.3

## 개요
원본(soundgo)의 핵심(손 추적 + 실시간 사운드)을 유지하면서,
초등학교 6학년이 **음악 개념을 몸으로 체험**하도록 바꾼 버전입니다.

## 조작 (v1.2 핵심)
- ✊ 손 **펴고 있으면 무음** (연주 X)
- 👌 **엄지+검지를 모으면(핀치) 노트 ON** → 그 순간의 화면 영역 음이 정확히 발음
- 좌→우 이동 = 음 ↑ / 다른 칸으로 넘어가면 다음 노트 트리거 (또박또박)
- 위로 올릴수록 + 핀치 강할수록 **소리 크기 ↑**
- 풀면 노트 OFF (release)

→ 슬라이딩 톤(테레민·트럼본) 느낌 제거. 멜로디·미션 가능.

## 모드
- 자유 연주
- 실험1: 음 높이 (주파수 Hz 직관)
- 실험2: 소리 크기 (진폭)
- 실험3: 음계 비교 (메이저 vs 오음계)
- **실험4: 따라치기** — 시범 멜로디 자동 재생 → 그대로 따라치면 미션 ✓

## 표현(아티큘레이션)
- 또박또박 (스타카토) — 기본
- 이어지게 (레가토)
- 슬라이드 (포타멘토) — 기존 글리산도 느낌 원할 때만

## 음계·파형
- 음계: 도레미(메이저) / 오음계 — 키는 도(C4 = MIDI 60) 기준 2옥타브
- 파형: 사인(부드러움) / 삼각(맑음) / 사각(게임)

## 실행
```bash
cd soundgo-edu
python3 -m http.server 4173
```
브라우저에서 `http://localhost:4173` 접속 후 **시작하기** 클릭.

## 1차시(20분) 권장 흐름
1. (3분) 도입: "AI가 손을 어떻게 알아볼까?" 짧은 시연
2. (5분) 자유 연주 — 핀치·놓기·이동 감 익히기
3. (5분) 실험1·2·3 — 음 높이·크기·음계 체험
4. (5분) 실험4 따라치기 — 시범 멜로디 따라치기 미션
5. (2분) 정리: 오늘 키운 휴먼스킬(호기심·창의·문제해결) 자기 평가

## 미션 (자동 ✓)
- 도 → 미 → 솔 또박또박 치기
- 큰 소리(70%↑)와 작은 소리(20%↓) 만들기
- 오음계로 서로 다른 음 5개 이상 치기
- 실험4 따라치기 시범 멜로디 1개 성공
- 루프 스테이션으로 1개 이상 레이어 녹음

## 루프 스테이션 (v1.3 신규)

손으로 멜로디를 녹음하고 그 위에 새 레이어를 쌓는 라이브 루퍼.

**컨트롤**
| 버튼 | 동작 |
|---|---|
| ● REC | 1마디 카운트인 → N마디 녹음 → 자동 재생 |
| ▶ PLAY | 정지/재생 토글 |
| ⊕ OD | 재생 중 라이브 연주를 같은 루프에 누적 (오버더빙) |
| ✕ CLR | 모든 레이어 삭제 |
| 메트로놈 | 클릭 on/off (다운비트 강조) |
| BPM | 60~180 (기본 100) |
| 루프 길이 | 2 / 4 / 8 마디 |

**실습 예시 (5분)**
1. BPM 100, 4마디 설정, 메트로놈 ✓
2. REC → 카운트인 4박 후 자동 녹음 시작
3. 핀치로 도-미-솔-미 같은 짧은 멜로디 연주
4. 4마디 종료 시 자동 재생 시작 (loopSynth, 삼각파)
5. OD 누르고 라이브로 화음/리듬 추가 → 다시 OD로 종료
6. CLR로 비우고 다시 녹음

## v1.1 → v1.2 변경 (핵심)
- ✅ **핀치 = 노트 ON/OFF 트리거** (히스테리시스: 0.45 ON / 0.22 OFF)
- ✅ **AmplitudeEnvelope** 도입 (attack/release 표현)
- ✅ **이산 노트 트리거** — 다른 칸으로 넘어가면 새 노트 (슬라이딩 톤 제거)
- ✅ **화면 건반 시각화** — 음 영역 8~15칸, 현재 음 노란색 강조, 옥타브 도 초록 테두리
- ✅ **표현 선택** (스타카토·레가토·포타멘토)
- ✅ **실험4 따라치기** 모드 (자동 시범 + 정답 인식)
- ✅ **개념 정량 표시** ("도 대비 1.5×" 등 옥타브·배음 관계)
- ✅ 파형 3종 (사인·삼각·사각)
- ✅ "손 펴면 무음" 시각 안내 강화
