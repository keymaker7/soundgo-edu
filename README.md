# soundgo-edu (초6 체험형 음악)

## 개요
원본(soundgo)의 핵심(손 추적 + 실시간 사운드)을 유지하면서,
초등학교 6학년이 **음악 개념을 몸으로 체험**하도록 바꾼 버전입니다.

## 이번 버전 핵심
- 실험 모드 3종: 음 높이 / 소리 크기 / 음계
- 쉬운 용어: 주파수(Hz), 진폭(소리 크기), 파형
- 미션형 학습: 도-미-솔, 크기 대비, 5초 오음계 멜로디

## 실행
```bash
cd projects/soundgo-edu
python3 -m http.server 4173
```
브라우저에서 `http://localhost:4173` 접속 후 **시작하기** 클릭.

## 1차시(20분) 권장 흐름
1. (5분) 실험1: 오른쪽으로 갈수록 음이 높아짐 체험
2. (5분) 실험2: 핀치 + 손 높이로 소리 크기 조절 체험
3. (5분) 실험3: 메이저 vs 오음계 느낌 비교
4. (5분) 미션 3개 달성하기
